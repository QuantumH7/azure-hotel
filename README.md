# Azure Bay Hotel

A simple, responsive single-page hotel website built with HTML and CSS, with a touch of vanilla JavaScript for interactivity.

## Files
- `index.html` — page markup (JavaScript is inlined at the bottom)
- `index.css` — all styling

## Features
- Sticky navbar with scroll-spy highlighting and a mobile hamburger menu
- Hero section with call-to-action buttons
- Availability checker (date validation + result message)
- Room cards with a booking modal
- Amenities and image gallery
- Scroll-reveal animations and hover effects
- Contact form with confirmation message

## Run locally
Just open `index.html` in any browser (double-click it, or `file:///path/to/index.html`). No build step or server required.
